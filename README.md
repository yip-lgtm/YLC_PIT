# YLC_PIT

Yuet Lai Court soil nail + NFC pit progress tracker.

**Live (after enabling Pages):** https://yip-lgtm.github.io/YLC_PIT/

## Files
- `index.html` – UI
- `app.js` – grid logic, IndexedDB/localStorage persistence, photo support

## Features
- 124 NFC pits (triangular layout) + 26 soil nails
- Status: 未開始 → 已開挖 → 已灌 → 已核實
- Search, filter, photo upload, JSON export/import
- Pure client-side
